# Remike Dev — Portofolio

**Demo live:** [kirax-12.github.io/remike-dev-portofolio](https://kirax-12.github.io/remike-dev-portofolio/)

Website portofolio pribadi **Wiranata Sutoyo (Remike Dev)**, UI/UX designer dan game/web developer dari Indonesia.

Proyek unggulan: [Kirax Spoof](https://github.com/kirax-12/KiraxSpoof) — aplikasi desktop Tauri + Rust + React untuk kreator Roblox Studio. Situs ini memuat 33 proyek dengan filter kategori: tool web dengan demo live di GitHub Pages, plus studi kasus UI/UX (redesign SATUSEHAT dan MRT Jakarta) dan game Roblox Mount Nyong (156 rb+ visits) yang materi lengkapnya ada di [Figma](https://www.figma.com/design/GVxGbqbnPcPMCRZ2yEiyXj/PORTOFOLIO-WIRANATA-SUTOYO).

## Cara menjalankan

Tidak ada build step. Buka `index.html` langsung di browser, atau jalankan server statis:

```bash
npx serve .
```

## Struktur

- `index.html` — seluruh konten situs (satu halaman)
- `style.css` — tampilan neo-brutalist (krem, border tegas, aksen cerah), responsif untuk mobile
- `script.js` — tahun otomatis di footer + filter kategori proyek

## Teknologi

HTML · CSS · JavaScript murni, tanpa framework.
