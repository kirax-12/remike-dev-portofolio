# Remike Dev — Portofolio

**Demo live:** [kirax-12.github.io/remike-dev-portofolio](https://kirax-12.github.io/remike-dev-portofolio/)

Website portofolio pribadi **Wiranata Sutoyo (Remike Dev)**, developer aplikasi desktop dan web dari Indonesia.

Proyek unggulan: [Kirax Spoof](https://github.com/kirax-12/KiraxSpoof) — aplikasi desktop Tauri + Rust + React untuk kreator Roblox Studio. Situs ini juga memuat 20+ proyek web dengan tautan demo live ke GitHub Pages masing-masing proyek.

## Cara menjalankan

Tidak ada build step. Buka `index.html` langsung di browser, atau jalankan server statis:

```bash
npx serve .
```

## Struktur

- `index.html` — seluruh konten situs (satu halaman)
- `style.css` — tampilan neo-brutalist (krem, border tegas, aksen cerah), responsif untuk mobile
- `script.js` — tahun otomatis di footer

## Teknologi

HTML · CSS · JavaScript murni, tanpa framework.
